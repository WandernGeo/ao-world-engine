# Example City Art Style Guide

> **For the AO World Engine Open Source Example**

This is a **generic, clean modern style** suitable for any world. Replace with your own art direction.

---

## Color Palette

| Use | Hex | Description |
|-----|-----|-------------|
| Primary | `#3B82F6` | Clean blue |
| Secondary | `#10B981` | Fresh green |
| Background | `#1F2937` | Neutral dark |
| Surface | `#374151` | Card/panel |
| Text | `#F9FAFB` | High contrast |
| Accent | `#F59E0B` | Warm highlight |

---

## Typography

- **Headers**: Inter Bold, clean sans-serif
- **Body**: Inter Regular
- **Code/Data**: JetBrains Mono

---

## Visual Principles

### 1. Clean & Functional
- Minimal decoration
- Clear hierarchy
- Readable data displays

### 2. Neutral Aesthetic
- Not tied to any genre
- Works for sci-fi, fantasy, modern, historical
- Easy to reskin

### 3. Customization Points
```
Replace these to match your world:
- Color palette → Your genre colors
- Typography → Your font choices
- Icons → Your visual language
- Terminology → Your world's terms
```

## Example Customizations

### Cyberpunk
```css
--primary: #ff00ff; /* Neon pink */
--secondary: #00ffff; /* Cyan */
--background: #0a0a0a; /* Deep black */
```

### Fantasy
```css
--primary: #c9a227; /* Gold */
--secondary: #2d5a27; /* Forest green */
--background: #1a1a2e; /* Royal dark */
```

### Post-Apocalyptic
```css
--primary: #d97706; /* Rust orange */
--secondary: #78716c; /* Weathered gray */
--background: #1c1917; /* Ash dark */
```
